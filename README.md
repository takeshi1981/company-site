# スカイライン・テクノロジー — 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジー株式会社」の1ページ企業サイトです。

## コンセプト

社名の「スカイライン」から着想し、建築図面・ブループリントをモチーフにしたデザインで構成しています。

- 方眼グリッド、寸法線、座標注記など、図面らしいディテールをあしらったヒーローのビル群イラスト
- 各セクションを図面の「シート」に見立て、シート番号（SHEET 01/06 など）を付与
- ブループリントブルーを基調に、サンライズカラー（銅色）をアクセントとして使用
- ライト／ダーク両テーマに対応

## 構成

1. ヘッダー・ナビゲーション
2. お知らせ
3. ヒーロー（キャッチコピー・ビル群イラスト）
4. サービス（4つの専門領域）
5. 数字で見るスカイライン（実績数値）
6. 実績（導入事例3件）
7. 開発プロセス（5工程）
8. 会社概要
9. 採用情報
10. お問い合わせ
11. フッター

## ブラウザで開く手順

1. このリポジトリをクローン、またはダウンロードする
2. `index.html` をダブルクリックするか、ブラウザにドラッグ&ドロップして開く
   - もしくはブラウザのアドレスバーに `index.html` のファイルパスを入力する
3. 追加のビルドやインストール作業は不要です（単一のHTMLファイルのみで完結します）

外部フォント（Google Fonts）を読み込むため、インターネット接続がある状態で開くことを推奨します。
